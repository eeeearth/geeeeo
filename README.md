# geeeeo

**Status: Planned**

Rocks, bedrock, surface geology, and soil parent-material context are planned for eeeearth local scenes. deeeecomp develops living soil layers and their water, temperature, and nutrient state. Implementation of geeeeo has not started.

Learn the science in the [Earth systems guide](https://github.com/eeeearth/eeeearth/tree/main/docs/earth-systems), or watch the [live stream](https://www.youtube.com/@jt55401/live). The simulation covers local scenes and does not model every Earth system.
